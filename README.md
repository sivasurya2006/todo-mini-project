# Todo App

A clean and responsive **Todo List** web application built using **HTML, CSS, and JavaScript**. This beginner-friendly project demonstrates core frontend development concepts such as **DOM manipulation**, **event handling**, and **event delegation** while providing an intuitive interface for managing daily tasks.

---

## Description

The Todo App allows users to create, manage, and organize their daily tasks with a simple and modern user interface. Users can add new tasks, mark them as completed, delete tasks, and view the total number of active tasks.

This project was developed to practice fundamental JavaScript concepts and improve frontend development skills.

---

## Features

* Add new tasks instantly
* Input validation for empty tasks
* Mark tasks as completed
* Delete individual tasks
* Real-time task counter
* Responsive and modern user interface
* Glassmorphism-inspired design
* Gradient background with hover effects
* Event Delegation for efficient event handling
* Beginner-friendly and clean code structure
